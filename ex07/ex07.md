# Exercise 7 - Summing several numbers

## What we learned

- A loop can be used to read several values one by one.
- A total should be initialized before the loop starts.
- `ADD VALUE TO TOTAL` adds the current value to the running total.
- `PERFORM VARYING` is useful when you know how many times to repeat the loop.
- `ACCEPT` is used to read a number from the user.
- `DISPLAY` prints the final total after the loop ends.

## Example

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. EX07.

       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01 COUNTER PIC 9 VALUE 1.
       01 NUMBER PIC 999.
       01 TOTAL PIC 999 VALUE 0.

       PROCEDURE DIVISION.
           PERFORM VARYING COUNTER FROM 1 BY 1 UNTIL COUNTER > 5
               DISPLAY "Enter number " COUNTER ": "
               ACCEPT NUMBER
               ADD NUMBER TO TOTAL
           END-PERFORM

           DISPLAY "Total: " TOTAL
           STOP RUN.
```

## Compile and run

```cmd
cobc -x -free ex07.cob -o ex07.exe
ex07.exe
```
