# Exercise 1 - First COBOL Program

## What we learned

- A COBOL program starts with `IDENTIFICATION DIVISION`.
- `PROGRAM-ID` gives the program its name.
- `PROCEDURE DIVISION` contains the executable instructions.
- `DISPLAY` prints text to the console.
- A period `.` ends a COBOL instruction.
- `STOP RUN` ends the program.
- A COBOL source file should end with a newline.
- COBOL keywords are usually not case-sensitive.
- Free format is easier for beginners: `cobc -x -free ...`.
- The compiler must be called on the correct file and the output file is an executable `.exe`.

## Compile and run

```cmd
cobc -x -free ex01.cob -o ex01.exe
ex01.exe
```

This creates an executable from the COBOL source and runs it.
