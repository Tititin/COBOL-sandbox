# Exercise 2 - Input and greeting

## What we learned

- `DATA DIVISION` is used to declare variables.
- `WORKING-STORAGE SECTION` stores variables used by the program.
- A variable is declared with a level number, for example `01`.
- `PIC X(20)` defines a text field of 20 characters.
- `ACCEPT` reads user input from the console.
- We can combine text and variables in a `DISPLAY` statement.

## Example

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. EX02.

       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01 USER-NAME PIC X(20).

       PROCEDURE DIVISION.
           DISPLAY "Please enter your name: "
           ACCEPT USER-NAME
           DISPLAY "Hello, " USER-NAME "!"
           STOP RUN.
```

## Compile and run

```cmd
cobc -x -free ex02.cob -o ex02.exe
ex02.exe
```
