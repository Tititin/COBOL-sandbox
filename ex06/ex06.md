# Exercise 6 - Counting from 1 to 10

## What we learned

- A counter is a numeric variable used to track progress.
- `PERFORM VARYING` is useful to repeat an action while changing a value.
- `ADD 1 TO COUNTER` increases the counter value.
- We can use `DISPLAY` to print the counter each time.
- Loops are useful when the number of repetitions is known in advance.
- `END-PERFORM` closes the loop block.

## Example

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. EX06.

       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01 COUNTER PIC 99 VALUE 1.

       PROCEDURE DIVISION.
           PERFORM VARYING COUNTER FROM 1 BY 1 UNTIL COUNTER > 10
               DISPLAY COUNTER
           END-PERFORM
           STOP RUN.
```

## Compile and run

```cmd
cobc -x -free ex06.cob -o ex06.exe
ex06.exe
```
