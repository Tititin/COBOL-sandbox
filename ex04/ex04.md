# Exercise 4 - Decision-making with IF

## What we learned

- `IF` is used to test a condition.
- `ELSE` handles the alternative case.
- Comparison operators such as `=`, `<`, and `>` are used in conditions.
- A condition must be followed by the instructions to execute.
- `END-IF` closes an `IF` block.
- We can use nested conditions to handle multiple cases.

## Example

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. EX04.

       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01 SCORE PIC 999.

       PROCEDURE DIVISION.
           DISPLAY "Enter the score: "
           ACCEPT SCORE

           IF SCORE >= 90
               DISPLAY "Grade: A"
           ELSE IF SCORE >= 80
               DISPLAY "Grade: B"
           ELSE IF SCORE >= 70
               DISPLAY "Grade: C"
           ELSE IF SCORE >= 60
               DISPLAY "Grade: D"
           ELSE
               DISPLAY "Grade: F"
           END-IF
           STOP RUN.
```

## Compile and run

```cmd
cobc -x -free ex04.cob -o ex04.exe
ex04.exe
```
