# Exercise 3 - Arithmetic operations

## What we learned

- Numeric fields are declared with `PIC 9`, `PIC 99`, etc.
- `COMPUTE` is used to perform arithmetic operations.
- `COMPUTE TOTAL = FIRST-NUMBER + SECOND-NUMBER` calculates a sum.
- A result can be stored in a separate numeric variable.
- We can print a computed value with `DISPLAY`.
- `DISPLAY` is for output; the calculation must be done before printing.

## Example

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. EX03.

       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01 FIRST-NUMBER PIC 99.
       01 SECOND-NUMBER PIC 99.
       01 TOTAL PIC 99.

       PROCEDURE DIVISION.
           DISPLAY "Enter the first number: "
           ACCEPT FIRST-NUMBER
           DISPLAY "Enter the second number: "
           ACCEPT SECOND-NUMBER
           COMPUTE TOTAL = FIRST-NUMBER + SECOND-NUMBER
           DISPLAY "The sum is: " TOTAL
           STOP RUN.
```

## Compile and run

```cmd
cobc -x -free ex03.cob -o ex03.exe
ex03.exe
```
