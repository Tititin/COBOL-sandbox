# Exercise 5 - Repeating logic with PERFORM UNTIL

## What we learned

- `PERFORM UNTIL` repeats a block until a condition becomes true.
- The loop condition is checked at the start of each iteration.
- `ACCEPT` can be used inside the loop to get each new guess.
- We can combine `IF` and loops to create interactive programs.
- `END-PERFORM` closes a loop block.
- `END-IF` closes an `IF` block.

## Example

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. EX05.

       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01 SECRET-NUMBER PIC 9 VALUE 7.
       01 USER-GUESS PIC 9 VALUE 0.

       PROCEDURE DIVISION.
           DISPLAY "Welcome to the Number Guessing Game!"
           DISPLAY "Can you guess the number?"

           PERFORM UNTIL USER-GUESS = SECRET-NUMBER
               DISPLAY "Please enter your guess: "
               ACCEPT USER-GUESS

               IF USER-GUESS = SECRET-NUMBER
                   DISPLAY "Congrats! You guessed it!"
               ELSE IF USER-GUESS < SECRET-NUMBER
                   DISPLAY "Too low!"
               ELSE
                   DISPLAY "Too high!"
               END-IF
           END-PERFORM
           STOP RUN.
```

## Compile and run

```cmd
cobc -x -free ex05.cob -o ex05.exe
ex05.exe
```
