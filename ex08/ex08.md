# Exercise 8 - Displaying several names

## What we learned

- A list of values can be stored in an array.
- `PIC X(n)` is used for text data.
- `OCCURS n TIMES` defines how many elements the array contains.
- A loop can be used to display each item in sequence.
- `PERFORM VARYING` can control the array index.
- `DISPLAY` prints the value of a variable.
- We can use one loop to avoid repeating the same output statement several times.

## Example

```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. EX08.

       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01 NAMES.
           05 NAME-TABLE OCCURS 5 TIMES PIC X(20).
       01 COUNTER PIC 9 VALUE 1.

       PROCEDURE DIVISION.
           MOVE "Alice" TO NAME-TABLE(1)
           MOVE "Bob" TO NAME-TABLE(2)
           MOVE "Charlie" TO NAME-TABLE(3)
           MOVE "David" TO NAME-TABLE(4)
           MOVE "Eve" TO NAME-TABLE(5)

           PERFORM VARYING COUNTER FROM 1 BY 1 UNTIL COUNTER > 5
               DISPLAY NAME-TABLE(COUNTER)
           END-PERFORM
           STOP RUN.
```

## Compile and run

```cmd
cobc -x -free ex08.cob -o ex08.exe
ex08.exe
```
